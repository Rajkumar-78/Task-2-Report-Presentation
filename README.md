## Task 2 Report

This project analyzes sales data using Python and pandas.

### Visualizations
1. Monthly revenue
2. Revenue by region
3. Profit by product

### Report
The Jupyter Notebook can be exported to HTML using:

```powershell
jupyter nbconvert --to html notebooks/task2_analysis.ipynb --output-dir=reports
```

### Running the project

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

Run the notebook using Jupyter Notebook.
