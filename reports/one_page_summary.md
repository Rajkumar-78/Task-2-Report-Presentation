 Employee Data Analysis Report
 Problem
The aim of this project is to understand employee data and find out how many employees leave the company.

 Dataset
I used the IBM HR Analytics Employee Attrition dataset. It contains details about employee age, monthly income, department and attrition.

 Key Findings
1. The dataset contains employees from different departments.
2. Employees receive different monthly incomes.
3. Some employees have left the company, while others are still working.

 Recommendations
 The company should understand employee problems and try to improve their work environment.
 The company should provide better career opportunities to help retain employees.

 Limitations
The analysis uses only the available dataset. It may not include all the reasons why employees leave the company.

 Conclusion
This project helped me learn how to analyze data using Python and create charts to understand employee information.
